# D3 uncertainty-guided exploration：可行性审计与预注册设计

## 当前状态

`D3_uncertainty_guided_exploration` 当前仍为 `proposal_only_not_started`。本文件记录研究问题、只读 feasibility audit 和正式生成前必须冻结的治理边界；它不代表已经生成牌谱、训练模型或选择了探索参数。

本阶段只允许：

- 在 M0 与 D1 的现有 replay index 上用 `K0=70k` parent 做 Q/margin 分析；
- 按 phase、观察到的行为动作类型、自己是否已立直、合法动作数分桶；
- 统计 top-1/top-2 legal Q margin、选择第二动作的 parent-Q gap、动作语义跨越和诊断阈值覆盖率。

本阶段禁止生成新牌谱、修改原始日志、修改 file index、训练 checkpoint，或根据未来训练结果反向选择规则。

## 研究问题

D1 的纯 K0-view lineage 在三组 B250 评测中稳定劣于 M0。其 `70k greedy agreement` 接近 100%，与“没有足够的有效动作支持”这一机制假设一致，但 D1 同时改变了完整 replay lineage，不能把动作支持不足宣称为唯一因果来源。

D3 要回答的是：

> 在 K0 的低 margin 状态引入受控、可复现的探索，能否形成比纯 K0-view 更有用且不失控的 project-owned replay lineage？

这里的“有用”必须先用 parent-Q 支持、动作语义和行为分布描述；不能把低 margin 自动当成正确探索，也不能把 ext/reviewer/NAGA 当硬标签。

## 生成合同必须分别冻结的内容

在 feasibility facts 审核完成前，以下字段保持“待冻结”，不能用默认值偷偷进入生成器：

1. **触发条件**：哪些低 margin 状态允许探索；是否还需要阶段、立直或合法动作数限制。
2. **候选集合**：top-2、同语义动作、仅 discard-to-discard，还是其他合法动作。必须明确是否允许跨越 discard/reach/pass/副露语义。
3. **采样规则**：随机源、seed、按状态还是按局预算、概率如何确定，以及同一状态的复现规则。
4. **预算**：总体 parent agreement、平均 parent-Q gap、各动作语义比例和单局探索上限。
5. **停止条件**：探索覆盖过低、parent-Q gap 过高、动作分布或立直/副露/铳率出现预设畸变时停止生成，不继续凑满数据量。

这些字段必须在单独的 D3 generation contract 中一次性预注册。不能同时启动多个 threshold/probability 变体后挑表现最好的一个，也不能使用训练中途结果修改合同。

## 固定变量与 promotion control

当前固定参考为：

- `K0 = 70k` parent；
- `M0_operational_control` 为正式 promotion control；
- objective = `behavior_action_mc`；
- reward = `final_rank_mc`；
- legacy continuation 使用 preserved Adam moments；
- 后续若获准生成，评测仍使用固定的 B250 random-seat protocol，并按完整半庄统计；
- 不在 D3 引入 reviewer/NAGA/4.1b imitation、GRP、legal-mean objective、LR/CQL 网格或架构变化。

## 反自欺规则

- 不按最终顺位、Pt、target 或训练后表现选择探索状态；规则只能依赖生成时可见的 state、合法 mask 和 K0 parent Q。
- 不把 `Q(top-1)-Q(top-2)` 当 ground-truth regret；它只是 parent 内部不确定性代理。
- 不把更低 agreement 自动视为更好；必须同时检查动作语义、parent-Q gap、行为分布和后续同协议强度。
- 不把 M0/D1 的未配对均值相减，作为 D3 的因果证据。
- 生成、训练和评测使用互不重叠、预先固定的 seed 范围，并记录 commit、模型 SHA、native batch、CUDA/AMP 状态。
